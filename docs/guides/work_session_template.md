# Work Session Template

Use this template for documenting LLM work sessions.

## Session Header
```markdown
# Work Session: [Feature/Task Name]

**Date:** YYYY-MM-DD  
**Duration:** ~X hours  
**Objective:** Brief description of what you're trying to achieve
**LLM:** [Claude/GPT-4/etc] 
**Session Type:** [Implementation/Analysis/Debugging/Planning]
```

## Problem Statement
- What problem are you solving?
- What was the initial request or requirement?
- Include code examples of current vs desired state

## Design Decisions
Document key decisions made during the session:
- **Decision:** What was decided
- **Rationale:** Why this approach was chosen
- **Alternatives:** What other options were considered
- **Trade-offs:** What are the pros/cons

## Implementation Details
### Core Components Added/Modified
- List new classes, functions, or modules
- Include key code snippets
- Explain the logic flow

### Key Changes
- File modifications
- New dependencies
- Configuration changes

## Testing Strategy
- What tests were added
- Test coverage approach
- Edge cases considered

## Documentation Created/Updated
- New documentation files
- Updated existing docs
- API documentation changes

## Files Modified
### Core Implementation
- List of modified files with brief description

### Testing
- Test files added/modified

### Documentation
- Documentation files created/updated

## Performance Impact
- Runtime performance changes
- Memory usage impact
- Scalability considerations

## Usage Examples
Include practical examples showing:
- Basic usage
- Advanced scenarios
- Common patterns

## Future Considerations
- Potential improvements
- Known limitations
- Next steps

## Lessons Learned
- What worked well
- What could be improved
- Insights for future sessions

## Conclusion
- Summary of what was accomplished
- Success criteria met
- Overall assessment
